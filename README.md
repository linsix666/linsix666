## Featured project

### HR Management Platform

A full-stack web platform developed during my internship at WiseWare Solutions. It brings employee and administrator workflows together in one system, including:

- Attendance and working-hours tracking
- Holiday requests and approval workflows
- Training records and certificates
- Monthly reports and data exports
- Employee and administrator areas
- JWT authentication and role-based access

**Built with:** SvelteKit, TypeScript, Tailwind CSS, shadcn-svelte, FastAPI, PostgreSQL and Docker.

> The source code is private because this project was developed during a professional internship. Screenshots and further details are available in my [portfolio](https://linsix666.github.io/adrian-portfolio/).
